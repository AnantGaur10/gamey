# 2026-11-01: publish fixes for CrazyGames

Found while checking what was left to publish (Steel & Yield's real preview had turned up save and touch bugs that local testing missed).

- Gameplay pair: `runDuel` owns it (`startGameplay`/`stopGameplay`, idempotent), and `cleanup()` closes it. SKIP during tutorial Focus used to send start with no stop.
- Site mute: SDK `game.settings.muteAudio` + `addSettingsChangeListener`, through `adapter.portalMuted`/`onPortalMuteChange`. `AudioManager` keeps two flags: the player's (saved) and the site's (never saved). The site's wins: the speaker button shows off and can't override it, and the player's saved choice is left alone. Docs require this for Full.
- Build: `dist/basic.html` is renamed to `dist/index.html` after the build (`entryAsIndex` in `vite.config.ts`). Dev stays on `basic.html`.
- SETTINGS shows MUSIC only when `home-screen.mp3` or `duel.mp3` ships (`HAS_MUSIC`). Add tracks and the slider returns.
- Music README moved out of `public/` to `store/music-notes.md`, so `public/assets/music/` doesn't exist until music lands (`musicFiles()` copes). Page title is HIGH NOON DUEL. `store/metadata.md` touch controls now match the two-thumb scheme of 2026-10-26.

Verified on the build: speaker-output peak 0.042 with sound on, 0 with the site mute on, 0.049 after it's lifted, 0 when loaded with `?muteAudio=true`. New spec `tests/portal-events.spec.ts`, run on desktop-1280.
