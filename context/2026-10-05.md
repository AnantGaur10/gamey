## 3. No cursor on the death / revive screen (user report)
- Cause: `body.in-duel` (style.css: `cursor: none !important` on everything in `#app`) stayed on through the round end, so the revive overlay (USE TOKEN / BUY / WATCH AD / STAY DOWN) had no OS pointer. The `.revive button { cursor: pointer }` rule loses to the `!important`, and the crosshair freezes once `roundOver` is set, so there was no pointer at all.
- Fix (`home.ts` `endRound`): remove `in-duel` and hide the crosshair as soon as the round resolves (gameplay is over; `attemptFire` already ignores clicks after `roundOver`). The next `runDuel` re-adds it.
- Verified in a browser probe: during the duel the canvas cursor is `none`; on the revive overlay `in-duel` is gone, the crosshair is hidden, and every button's cursor is `pointer`; 0 page errors. `npm test` PASS (1.42MB), duel-combat 12/12 desktop + mobile.
