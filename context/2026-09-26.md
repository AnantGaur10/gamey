## 1. Focus / bloom / tap pads (locked)

- Flow: `RoundIntro -> Focus 3.0s fixed -> DRAW! -> Fire (6-shooter) -> Resolve`. Aim hard-locked during Focus; same pointer flips from focus to fire at `DRAW!`.
- Two bottom-corner focus pads (`~128px @DPR=1`, min 72px touch target), canvas-docked, safe-area aware (`env(safe-area-inset-*)`), `touch-action:manipulation`, `user-select:none`. Stay reachable in all QA iframes + portrait side-bars; hide 150ms after `DRAW!`.
- Input: pointer-only (no keyboard, per user pick). `pointerdown` starting inside pad = `FocusTap{tick,padId}`, tracked by `pointerId` (dual-thumb OK). Right-click / Ctrl+click ignored, context menu suppressed. Effective cap 12 taps/s shared.
- Inside: `-0.35° * 1/(1+0.18*taps)` per tap + hold `-0.30°/s` fallback. Clamp to `bloomMin[gun]` floor — perfect play never pinpoint.
- Outside pad during Focus: `FocusMiss{tick}` → `bloom += 0.25°` to `bloomMax` + red pulse. Not foul, just accuracy tax. Single accident survivable.
- Post-DRAW regrow `+0.5°/s` if holding without firing.
- Bloom unit: angular radians in sim, projected screen circle in render (auto-corrects distance 9-14m + camera dolly). Vector circle, no texture. Readable at DPR=1, mobile 800x450, night ambient 0.15. Tutorial: pulsing pads + `TAP!` → flash `DRAW!`, visuals > text, skippable, `GameplayStart` still at RoundIntro.
- Risk noted: pointer-only fails keyboard-only desktop QA if flagged → fallback is re-enable Space at half-rate, no pad change.

## 2. AI: reaction x accuracy (locked)

- Per-character profile: `{ reactionBaseMs, accuracyMult, focusQuality 0..1, hp, gunId }`.
- `reaction = reactionBase * 0.97^round * 0.94^level`, floor 180ms (from 09-24).
- `shrinkSim = lerp(bloomStart, bloomMin, focusQuality + seededNoise)`; `aimError = gaussian() * accuracyMult * distanceFactor`. Death chance emerges from both axes, no kill-RNG. Same projectile/ragdoll path; `Fire{pos,dir,gunId,tick}` over `LocalTransport` now, `CrazyRoomTransport` later.

## 3. Recoil + flinch (locked)

- Recoil (own shot): `bloom += recoilAdd (~0.9°)` to `bloomMax` + visual gun-kick/crosshair pop only (never moves world camera). Recovery `0.4°/s` rewards pacing.
- Flinch (hit taken, body only — head ends duel): `aimPitch += 1.2° up + bloom += 0.5°`, linear decay over 400ms in fixed 60Hz sim. Stacks, caps `3° / +1.5° bloom`. Pure `Flinch{tick,amount}` event; symmetric player + AI (`aimError += flinch`). Offset on aim ray + crosshair only.

## 4. Guns + gold economy (locked)

- Schema: `Gun { damage, accuracy->{bloomStart,bloomMin,focusPerTap}, extra:{kind:lifesteal|gold|none,value}, drawMs, recoilAdd, recoilRecovery, kick }`. One bloom source of truth, no separate spread.
- `extra` exclusive: `lifesteal` = heal `value%` of actual dealt per hit, capped 15 HP/hit, clamped to max; `gold` = `+value%` gold per hit/kill but `-15% damage, +0.2° bloomMin` vs tier (economy-vs-power, never pure upgrade). Default (no extra) = highest damage.
- Earn: flat per round win (e.g. 10g Best-of / 15g Deathmatch + streak step) + 2g loss consolation + kill bonus with gold gun. No per-damage gold.
- Spend: between runs only (home armory), never mid-run/duel. Starter competitive; gold guns optional. Passes progression-tax QA.
- Bases (HP=100): default `49`, lifesteal `38` (+20% steal), gold `37` (+40% gold). See §5 for TTK proof. Prices TBD — no numbers locked.

## 5. Damage falloff + TTK (locked)

- Global bilinear curve, same factor all guns (user overrode linear→bilinear, kept global): `ret 1.00@9m / 0.92@11m / 0.70@14m`, lerp within legs. Computed once per round from locked `duelDist`, not per-bullet. Deterministic, fixed-tick, net-safe.
- `bodyDmg = base * ret(dist)`; `headDmg = INSTANT KILL any range`, skips falloff/HP.
- No 2-shot class: default `49` → 9m `49.0` (2 hits=98, needs 3rd) → 11m `45.1` (needs 3rd) → 14m `34.3` (3 hits=102.9 kills). 3-everywhere, never 2.
- Others 3→4 past 11m: `38→35.0→26.6`, `37→34.0→25.9` (3 hits=77 at 14m, needs 4th). Emergent, not hardcoded.
- Ripple: lifesteal on post-falloff actual; gold flat unaffected; double-KO body lethal uses `bodyDmg >= hpAtFire`, head lethal always true; ragdoll impulse unscaled (visual only); AI same curve.

## 6. Life / revive (locked, singleplayer only)

- On accept: consume token, freeze score/streak (no loss counted), restart same round/duel from Focus countdown (propose re-roll distance), player HP=1, opponent full HP, ammo/bloom reset.
