# Context — 2026-09-29 (Blender MCP in WSL2)

## 1. Decision: Blender lives in WSL2, not Windows

- OpenCode + `uvx` run in WSL2 → MCP socket is `localhost:9876`. Same-side Blender = zero network config. Windows Blender would need `BLENDER_HOST` + firewall work per reboot.
- GLB output lands directly in repo paths. No `\\wsl$\` translation.
