# Audio Assets

This folder contains music and sound effects for the game.

## Music Files (Add Later)

Place your royalty-free music tracks here:

- **home-screen.mp3** - Calm, inviting Western theme for the home menu
- **duel.mp3** - Intense, dramatic standoff music for duel gameplay

## Recommended Format

- **Format:** MP3 (best browser compatibility)
- **Alternative:** OGG or WAV
- **Bitrate:** 128kbps (good quality, small size)
- **Length:** 60-120 seconds (will loop automatically)
- **Size:** ~1-2MB per track

## Royalty-Free Music Sources

Safe sources to find tracks (no copyright issues):

1. **Incompetech.com** (Kevin MacLeod) - CC0, commercial use allowed
   - Search for: "Western", "Saloon", "Tense", "Standoff"
   
2. **Freesound.org** - Filter by CC0 (Public Domain)

3. **YouTube Audio Library** - Free, requires attribution in game description

4. **OpenGameArt.org** - Game-safe music

## Sound Effects

The gunshot sound is **generated programmatically** (no file needed).

Optional SFX files you can add:
- **hit-body.mp3** - Body hit impact sound
- **hit-head.mp3** - Headshot sound (can reuse gunshot)

## Notes

- All audio files are **optional** - game works fine without them
- Missing files are silently skipped (no crashes)
- Audio is muted during ads automatically (CrazyGames compliant)
- User can toggle mute via button in home screen
- Mute state is saved in progress storage
