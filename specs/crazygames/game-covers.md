# CrazyGames — Game Covers + Metadata

Source: https://docs.crazygames.com/requirements/game-covers
Covers = storefront. Decide clicks in <1s. Update occasionally (spike on refresh, seasonal OK, don't over-rotate).

## Cover images (3 mandatory, consistent style)

- Landscape 16:9 `1920x1080`
- Portrait 2:3 `800x1200`
- Square 1:1 `800x800`

Restrictions:
- No borders, no extra text (`New`, `Updated`, `Play`, `Play now`), no store/platform icons, no unlicensed copyrighted visuals, no blurry/pixelated.

Guidelines:
- Don't just screenshot. Use hero character / big title / artistic hook. Hover preview shows gameplay anyway.
- Keep simple — readable on small screens.
- Put game name on cover, memorable + distinct.
- Stylized font matching aesthetic (not Times New Roman). Free fonts OK.
- Inspo: Steam/Epic top games in genre. Pro help: Fiverr/Upwork.

## Preview video

Purpose: hover autoplay. Show best 15-20s: expensive cars / full lobbies / intense fights / progression.

Requirements:
- Length 15-20s max (cut at 20s), size ≤50MB.
- Resolutions mandatory: 1080p landscape 16:9 + 1080p portrait 2:3.
- No: black screens/logo transitions, top/bottom black bars, default cursor, `Play Now`/promo text, app/social icons, fast-forward (they auto-speed slightly), sound.
- First frame = static cover (seamless thumb->video).
- Tools: ClipChamp (Win), iMovie (Mac), HandBrake for conversion.

## Submission metadata

Provide qualitative description + controls + covers/videos in Developer Portal. Keep name/imagery truthful to genre; change name/art only on major update/overhaul.
